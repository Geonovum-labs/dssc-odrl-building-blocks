# LDP3 Remove Spatial Reference

Data-transfer policy requiring removal of geometry or spatial reference before sharing attributes.

## Notes

This is an experimental ODRL profile for location-data transfer policies. Connector interoperability depends on the availability of matching policy-engine bindings and PEP/Location Privacy Proxy functions.

Negative tests are named with the `-fail` suffix so the OGC Building Blocks validation pipeline treats them as expected failures.
